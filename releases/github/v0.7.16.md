### Fixed

- Blocked exploitation of a Node.js security vulnerability (CVE-2026-111497) through LAN sync. Previously, an attack was possible only with sync enabled and an attacker on the same local network specifically targeting Foliole.
- Upgrading the app or restoring an older backup no longer leaves it unresponsive for extended periods.
- Prevented occasional incorrect merges during sync conflicts.
