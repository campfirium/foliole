### New

- Readwise API mode: sync Readwise Reader content on demand without going through Obsidian.
- Clean formatting: define custom rules, preview the result, and run cleanup directly.
- Search backup content: find content directly in previous backups.
- Compact database: manually reclaim unused database space.
- LAN sync: early support is now available and remains under development.

### Improved

- Image viewing, saving images locally, and attachment management received a range of updates.
- Backup management now supports retention priorities across time-based tiers, among other updates.
- The editor now supports list indentation adjustments and task status toggling.

### Fixed

- macOS appearance now follows the system theme correctly.
- Automatic Untitled numbering has been corrected.
