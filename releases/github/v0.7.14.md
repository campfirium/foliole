### New

- Readwise API mode syncs Readwise Reader content on demand without going through Obsidian.
- Clean formatting lets you define custom rules, preview the result, and run the cleanup directly.
- Content in previous backups is now searchable.
- Database compaction can be run manually to reclaim unused space.
- Early desktop sync support is now available and remains under development.

### Improved

- Image viewing, saving images locally, and attachment management received a range of updates.
- Backup management now supports retention priorities across time-based tiers, among other updates.
- The editor now supports list indentation adjustments and task status toggling.

### Fixed

- macOS appearance now follows the system theme correctly.
- Automatic Untitled numbering has been corrected.
