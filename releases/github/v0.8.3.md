### New

- 🖥️ **SuperMemo import (preview):** Import a SuperMemo collection into Foliole and update the import when conversion rules improve or you adjust the import settings.
- **Image region selection:** Select an area on the original image, then bring it into focus or display only that area. Both operations are non-destructive.
- 🖥️ **History panel:** Search recently opened materials, return to the last one you edited, and pin materials for quick access.
- 🖥️ **Adaptive sidebar layout:** Choose how the left and right sidebars appear and how wide they are at different window widths.
- 🖥️ **Merge another library:** Bring another library into your current library.
- Initial support for Hindi in the interface and guides.
- 📱 **Restore from backup:** Restore a library from a phone backup.
- 📱 Create and manage Dives and entries in Virtual, and save keyword searches to Virtual.
- 📱 Create clozes from formulas.
- 📱 The text selection menu now offers “Select paragraph” and custom web lookups.
- 📱 View backlinks and copy a topic’s full Markdown text.
- 📱 Open a recently viewed topic from the search screen.

### Improved

- 🖥️ The PDF reader adds “Automatically expand width” and more zoom levels.
- 🖥️ The command palette can now find settings and action tips.
- Each list remembers its own sort order. Desktop and mobile sync their sort orders separately.
- Breadcrumbs can expand to show the full path.
- 📱 Breadcrumbs let you jump from derived material back to the original passage.
- 🖥️ Click a wiki link to a topic that doesn’t exist yet to create it directly.
- Improved WebDAV sync compatibility.
- 🖥️ **Aide** lets you configure its context scope and edit permissions, and set custom instructions that apply globally.
- 🖥️ Agent Control can import Topic reading schedules and Item review history.
- 📱 The Browse home screen now has a “Show child topics” option.
- 📱 Lists update immediately when you create a folder, topic, or item, or move materials to Trash.
- 📱 Initial sync is faster.
- 📱 Folder backups are faster and can show backup progress.
- 📱 The library and Trash now support batch actions.

### Fixed

- Other materials continue syncing when a data object is too large to sync.
- 🖥️ The PDF reader preserves your reading position when you zoom.
- 🖥️ You can grade an item immediately after editing it.
- 🖥️ Splitting a topic preserves its existing highlights.
- 🖥️ Batch imports include all selected files.
- 🖥️ EPUB files with complex content now import correctly.
- 🖥️ Sequential reading continues past deleted topics.
- The HTML import parser includes upstream security fixes.
- In dark mode, image cloze masks fully cover the answers.
- Deleted folders stay in Trash, and permanently deleted materials stay deleted after sync.
- 📱 Your reading position is preserved when you reopen a topic or switch editing modes.
- 📱 The page scrolls automatically when you drag a highlight handle to the edge of the screen.
- 📱 Improved error messages and retries for folder backups.
