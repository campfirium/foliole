# Sprawdzanie: Utrwal wiedzę

Gdy pojawi się element utworzony przez Zamknij, najpierw spróbuj przypomnieć sobie odpowiedź.
Następnie oceń ją na dolnym pasku działań: wybierz Znowu, jeśli odpowiedź umknęła (lub naciśnij 1), Ciężko, jeśli pamiętasz ją częściowo (lub naciśnij 2), Dobrze, jeśli ją pamiętasz (lub naciśnij 3), oraz Łatwe, jeśli była zbyt prosta (lub naciśnij 4).
Ocena wpływa na termin ponownego wyświetlenia, a samo przywoływanie odpowiedzi wzmacnia pamięć.
