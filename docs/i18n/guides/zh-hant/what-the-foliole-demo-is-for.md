# 線上體驗 Foliole

也許你是 SuperMemo 的長期使用者，想看看 Foliole 有什麼不同。

也許你經常使用 Obsidian 等閱讀與筆記工具，希望材料不只停留在閱讀與標註。

也許你剛接觸漸進閱讀，還不確定它是否適合自己。

為了讓你更直接地體驗 Foliole，我們特別建立了這套線上體驗版。

無須安裝，開啟網頁即可直接體驗。你可以在這裡閱讀會持續更新的 Foliole Guides，也可以匯入自己的 Markdown 文件，走過漸進閱讀的核心流程。

線上體驗版提供模擬日期功能，方便你快速體驗 Foliole 的材料排程。設定面板中的「桌面設定預覽」會顯示桌面版的完整設定，讓你了解 Foliole 的功能結構；在這裡做的調整不會影響線上體驗版。

線上體驗版會將資料儲存在瀏覽器本機，請勿將它當作唯一備份。它也不包含桌面版的多項核心功能，包括 PDF、EPUB 與圖片檢視、外部文件庫、進階搜尋、Obsidian 整合、Readwise Reader 整合、Markdown 鏡像、區域網路同步等。

線上體驗版會隨桌面應用程式持續更新，也可能出現與桌面版不同的問題。你可以透過左側工具列直接提交意見，也歡迎在 GitHub 關注專案進度、回報問題或參與討論。
