# Prueba: Consolida lo aprendido

Cuando aparezca un elemento creado a partir de un Cloze, intenta recordar primero la respuesta.
Después, puntúalo en la barra de acciones inferior: elige Otra vez si no lo recordaste (o pulsa 1), Duro si lo recordaste en parte (o pulsa 2), Bueno si lo recordaste (o pulsa 3) y Fácil si fue demasiado sencillo (o pulsa 4).
La puntuación influye en cuándo volverá a aparecer, y el propio acto de ponerte a prueba ayuda a reforzar la memoria.
