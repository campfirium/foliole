# Lectura: Divide el conjunto en partes

No es necesario terminar una lectura de una sola vez.
Según el contexto, puedes hacer que el contenido actual vuelva a aparecer pronto (Soon en la barra de acciones inferior, o pulsa 1), más adelante (Later, o pulsa 2), después de otra pasada de lectura (Read, o pulsa 3), o dejar de mostrarlo automáticamente cuando hayas terminado (Dismiss, o pulsa 4).
