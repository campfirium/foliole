# Test : Ancrer les connaissances

Lorsqu’un élément créé à partir d’un Cloze apparaît, essayez d’abord de vous rappeler la réponse.
Évaluez-la ensuite dans la barre d’actions inférieure : choisissez Encore une fois si vous l’avez oubliée (ou appuyez sur 1), Difficile si vous vous en souvenez partiellement (ou appuyez sur 2), Bon si vous vous en souvenez (ou appuyez sur 3), et Facile si la réponse était trop évidente (ou appuyez sur 4).
Votre évaluation détermine quand l’élément réapparaîtra, et le fait de vous tester renforce lui-même la mémoire.
