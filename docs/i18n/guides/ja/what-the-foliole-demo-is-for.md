# Folioleデモでできること

長年SuperMemoを使っていて、Folioleとの違いを確かめたい方もいるでしょう。

Obsidianなどの読書・ノートツールを日常的に使い、資料を読む、ハイライトするだけで終わらせたくない方もいるでしょう。

インクリメンタルリーディングを初めて知り、自分に合うかまだ分からない方もいるでしょう。

Folioleを直接体験しやすくするため、このオンラインデモを用意しました。

インストールは不要です。ページを開けば、ブラウザですぐに試せます。ここでは、今後も更新されるFoliole Guidesを読んだり、自分のMarkdown文書をインポートしてインクリメンタルリーディングの基本的な流れを体験したりできます。

オンラインデモでは日付をシミュレートできるため、Folioleによる資料のスケジューリングを短時間で試せます。設定パネルにはデスクトップ設定のプレビューがあり、デスクトップ版の設定全体を見ながらFolioleの機能構成を把握できます。ここで設定を変更しても、オンラインデモには反映されません。

オンラインデモのデータはブラウザ内に保存されます。唯一のバックアップとしては使用しないでください。また、PDF・EPUB・画像の表示、外部文書ライブラリ、検索機能の拡張、Obsidian連携、Readwise Reader連携、Markdownミラー、ローカルネットワーク同期など、デスクトップ版の主要機能の多くは含まれていません。

オンラインデモはデスクトップアプリとともに更新され、デスクトップ版とは異なる問題が起きることもあります。左サイドバーから直接フィードバックを送信できます。GitHubでプロジェクトをフォローしたり、問題を報告したり、議論に参加したりすることもできます。
