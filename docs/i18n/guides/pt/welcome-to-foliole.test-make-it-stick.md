# Teste: Fixe o conhecimento

Quando um item criado por um Cloze aparecer, tente primeiro se lembrar da resposta.
Em seguida, avalie na barra de ações inferior: escolha Novamente se não lembrou (ou pressione 1), Difícil se lembrou parcialmente (ou pressione 2), Bom se lembrou (ou pressione 3) e Fácil se foi simples demais (ou pressione 4).
A avaliação afeta quando o item aparecerá novamente, e o próprio ato de testar a memória ajuda a fortalecê-la.
