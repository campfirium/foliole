# Проверка: Закрепите знания

Когда появится элемент, созданный из Клоуза, сначала попробуйте вспомнить ответ.
Затем оцените его на нижней панели действий: выберите снова, если не вспомнили (или нажмите 1), Жесткий, если вспомнили частично (или нажмите 2), Хорошо, если вспомнили (или нажмите 3), и Легко, если задание оказалось слишком простым (или нажмите 4).
Оценка влияет на то, когда элемент появится снова, а само извлечение ответа из памяти помогает укрепить запоминание.
