# Testen: Wissen verankern

Wenn ein aus einem Lückentext erstelltes Testelement erscheint, versuche zuerst, dich an die Antwort zu erinnern.
Bewerte sie anschließend in der unteren Aktionsleiste: Wähle Schon wieder, wenn du sie nicht wusstest (oder drücke 1), Schwer, wenn du dich teilweise erinnert hast (oder drücke 2), Gut, wenn du dich erinnert hast (oder drücke 3), und Einfach, wenn sie zu leicht war (oder drücke 4).
Deine Bewertung beeinflusst, wann das Testelement erneut erscheint. Auch das aktive Abrufen selbst stärkt das Gedächtnis.
