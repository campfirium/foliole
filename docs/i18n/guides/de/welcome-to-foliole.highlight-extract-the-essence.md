# Hervorheben: Das Wesentliche herausarbeiten

Markiere den Text, den du herauslösen möchtest. Daraufhin erscheint die schwebende Werkzeugleiste.

Wähle dort Hervorheben oder drücke Alt + Z (Windows) oder Option + Z (Mac), um die Passage hervorzuheben und daraus ein neues untergeordnetes Thema zu erstellen.
