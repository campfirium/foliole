# Testen: Wissen verankern

Wenn ein aus einem Lückentext erstelltes Testelement erscheint, versuche zuerst, dich an die Antwort zu erinnern, und tippe dann auf Antwort anzeigen.
Bewerte sie anschließend in der unteren Aktionsleiste: Schon wieder, wenn du sie nicht wusstest, Schwer, wenn du dich teilweise erinnert hast, Gut, wenn du dich erinnert hast, und Einfach, wenn sie zu leicht war.
Deine Bewertung beeinflusst, wann das Testelement erneut erscheint. Auch das aktive Abrufen selbst stärkt das Gedächtnis.
