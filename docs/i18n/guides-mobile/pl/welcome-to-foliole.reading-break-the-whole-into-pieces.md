# Czytanie: Podziel całość na części

Nie musisz kończyć czytania za jednym razem.
W zależności od sytuacji wybierz na dolnym pasku działań: Soon wyświetli bieżącą treść ponownie wkrótce, Later później, Read po kolejnym etapie czytania, a Dismiss przestanie wyświetlać ją automatycznie po zakończeniu.
Dotknięto nie tego przycisku? Przesuń palcem od lewej krawędzi ekranu, aby cofnąć.
