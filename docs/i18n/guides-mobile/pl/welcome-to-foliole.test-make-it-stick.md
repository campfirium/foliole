# Sprawdzanie: Utrwal wiedzę

Gdy pojawi się element utworzony przez Zamknij, najpierw spróbuj przypomnieć sobie odpowiedź, a potem dotknij Pokaż odpowiedź.
Następnie oceń ją na dolnym pasku działań: Znowu, jeśli odpowiedź umknęła, Ciężko, jeśli pamiętasz ją częściowo, Dobrze, jeśli ją pamiętasz, oraz Łatwe, jeśli była zbyt prosta.
Ocena wpływa na termin ponownego wyświetlenia, a samo przywoływanie odpowiedzi wzmacnia pamięć.
