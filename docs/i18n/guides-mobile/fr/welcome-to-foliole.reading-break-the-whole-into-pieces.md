# Lecture : Découper l’ensemble en plusieurs parties

Une lecture n’a pas besoin d’être terminée en une seule fois.
Selon le contexte, choisissez dans la barre d’actions inférieure : Soon fait réapparaître le contenu actuel bientôt, Later plus tard, Read après un nouveau passage de lecture, et Dismiss arrête de l’afficher automatiquement une fois terminé.
Mauvais bouton ? Balayez depuis le bord gauche de l’écran pour annuler.
