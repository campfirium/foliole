# Test : Ancrer les connaissances

Lorsqu’un élément créé à partir d’un Cloze apparaît, essayez d’abord de vous rappeler la réponse, puis touchez Afficher la réponse.
Évaluez-la ensuite dans la barre d’actions inférieure : Encore une fois si vous l’avez oubliée, Difficile si vous vous en souvenez partiellement, Bon si vous vous en souvenez, et Facile si la réponse était trop évidente.
Votre évaluation détermine quand l’élément réapparaîtra, et le fait de vous tester renforce lui-même la mémoire.
