# Проверка: Закрепите знания

Когда появится элемент, созданный из Клоуза, сначала попробуйте вспомнить ответ, а затем нажмите Показать ответ.
Оцените его на нижней панели действий: снова, если не вспомнили, Жесткий, если вспомнили частично, Хорошо, если вспомнили, и Легко, если задание оказалось слишком простым.
Оценка влияет на то, когда элемент появится снова, а само извлечение ответа из памяти помогает укрепить запоминание.
