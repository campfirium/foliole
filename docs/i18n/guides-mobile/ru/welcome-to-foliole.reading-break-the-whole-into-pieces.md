# Чтение: Разделите целое на части

Необязательно завершать чтение за один раз.
В зависимости от ситуации выберите на нижней панели действий: Soon скоро снова покажет текущий материал, Later — позже, Read — после очередного этапа чтения, а Dismiss больше не будет показывать его автоматически, когда работа закончена.
Нажали не ту кнопку? Проведите от левого края экрана, чтобы отменить.
