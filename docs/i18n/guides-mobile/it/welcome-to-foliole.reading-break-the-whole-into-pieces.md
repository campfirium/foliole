# Lettura: Dividi l’insieme in parti

Non è necessario completare una lettura in un’unica volta.
In base al contesto, scegli nella barra delle azioni in basso: Soon mostra di nuovo presto il contenuto corrente, Later più avanti, Read dopo un altro passaggio di lettura, e Dismiss smette di mostrarlo automaticamente quando hai finito.
Hai toccato il pulsante sbagliato? Scorri dal bordo sinistro dello schermo per annullare.
