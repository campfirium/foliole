# Lectura: Divide el conjunto en partes

No es necesario terminar una lectura de una sola vez.
Según el contexto, elige en la barra de acciones inferior: Soon vuelve a mostrar el contenido actual pronto, Later más adelante, Read después de otra pasada de lectura, y Dismiss deja de mostrarlo automáticamente cuando hayas terminado.
¿Tocaste el botón equivocado? Desliza desde el borde izquierdo de la pantalla para deshacerlo.
