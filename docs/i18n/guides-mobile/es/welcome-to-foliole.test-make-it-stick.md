# Prueba: Consolida lo aprendido

Cuando aparezca un elemento creado a partir de un Cloze, intenta recordar primero la respuesta y luego toca Mostrar respuesta.
Después, puntúalo en la barra de acciones inferior: Otra vez si no lo recordaste, Duro si lo recordaste en parte, Bueno si lo recordaste y Fácil si fue demasiado sencillo.
La puntuación influye en cuándo volverá a aparecer, y el propio acto de ponerte a prueba ayuda a reforzar la memoria.
