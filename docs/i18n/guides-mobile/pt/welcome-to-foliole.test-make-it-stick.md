# Teste: Fixe o conhecimento

Quando um item criado por um Cloze aparecer, tente primeiro se lembrar da resposta e depois toque em Mostrar resposta.
Em seguida, avalie na barra de ações inferior: Novamente se não lembrou, Difícil se lembrou parcialmente, Bom se lembrou e Fácil se foi simples demais.
A avaliação afeta quando o item aparecerá novamente, e o próprio ato de testar a memória ajuda a fortalecê-la.
