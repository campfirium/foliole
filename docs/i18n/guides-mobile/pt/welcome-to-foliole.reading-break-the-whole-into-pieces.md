# Leitura: Divida o todo em partes

A leitura não precisa ser concluída de uma só vez.
De acordo com o contexto, escolha na barra de ações inferior: Soon exibe o conteúdo atual novamente em breve, Later mais tarde, Read depois de outra etapa de leitura, e Dismiss para de exibi-lo automaticamente quando você terminar.
Tocou no botão errado? Deslize a partir da borda esquerda da tela para desfazer.
