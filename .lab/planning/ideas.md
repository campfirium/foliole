# Ideas Queue

Use this file only as a lightweight memory queue.

## Commands
- `记个想法：...` -> append one raw idea paragraph to `Pending`.
- `看看想法` -> read `Pending`, do lightweight evaluation, suggest what to hand off.
- `交接这个想法：...` (or natural equivalent, e.g. `那就做这个吧`) -> move selected idea out of `Pending` and turn it into next task input.
