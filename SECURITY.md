# Security Policy

## Reporting a Vulnerability

Please do not report security issues in public GitHub Issues or Discussions.

Contact the maintainer through a private channel. Include:

- A short description of the issue.
- Steps to reproduce.
- The Foliole version or commit.
- The affected platform: desktop, Android companion, sync, import, or release package.
- Any sample files or logs needed to reproduce, with private reading data removed.

## Scope

Security reports are especially useful when they involve unsafe rendering, unexpected file access, data loss, sync overwrite risk, dependency risk, native bridge boundaries, or package integrity.
