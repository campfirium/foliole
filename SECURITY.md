# Security Policy

## Supported Versions

Foliole is currently in active pre-release development. Security reports should target the latest commit on the `dev` branch unless a release note states otherwise.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting flow for this repository so the details can be reviewed and fixed before public disclosure:

https://github.com/campfirium/foliole/security/advisories/new

When reporting, include:

- A clear description of the issue.
- Steps to reproduce or a minimal proof of concept.
- The affected platform or surface, such as desktop, Android, companion, sync, import, or update flow.
- Any known impact or workaround.

We will review valid reports privately, coordinate a fix, and publish security details only after the issue is resolved or otherwise safe to disclose.
